# schichtfrei.com

Static website for the Schichtfrei app, served by GitHub Pages at https://schichtfrei.com.

- `index.html`: short app intro and store links
- `datenschutz.html`, `impressum.html`, `nutzungsbedingungen.html`: legal pages; the app links to these
- `CNAME`: custom domain for GitHub Pages

Edit a page directly on GitHub (pencil icon); the site updates within a minute or two.
